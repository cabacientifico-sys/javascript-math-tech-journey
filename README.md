# 🚀 Mi viaje en JavaScript: Lógica, Matemáticas y Tecnología

Bienvenido a mi portafolio de programación. Soy un estudiante de 14 años enfocado en construir una base sólida en Matemáticas y Tecnologías con el objetivo de acceder a programas universitarios.

Este repositorio documenta mi progreso en el curso *JavaScript Algorithms and Data Structures* de freeCodeCamp y mis propios proyectos aplicados.

## 🧠 Enfoque del Aprendizaje
No solo escribo código; busco entender la lógica matemática que hay detrás. 
* Trato las variables (`let`, `const`) como incógnitas y constantes algebraicas.
* Uso las funciones como mappings (entradas y salidas).
* Aplico la programación para resolver problemas reales de mi entorno.

## 💻 Proyectos

### 1. Calculadora (`calculadora.js`)
- **Concepto:** Usare este script para entender las bases del lenguaje js y como usarlo.
- **Habilidades demostradas:** Uso de variables, operaciones aritméticas básicas, y formateo de salidas numéricas (`.toFixed()`).

### 2. Bot Interactivo Básico (Próximamente)
- **Concepto:** Primer script de lógica condicional (`if/else`) y control de flujo.
- **Habilidades demostradas:** Árboles de decisión y lógica booleana.
